# 📽️ Projector Music Visualizer (Музыкальный визуализатор для проектора)

Легковесный, ультра-производительный визуализатор музыки для ПК на Windows, спроектированный специально для вывода на подключенный проектор или второй монитор.

Захватывает любой звук, играющий на компьютере (Spotify, SoundCloud, YouTube, браузер, игры, плееры) **напрямую из Windows WASAPI Loopback** в 100% цифровом качестве — без микрофонов, без виртуальных кабелей (Stereo Mix) и без необходимости давать разрешения в браузере.

---

## 🌟 12 Визуальных Пресетов

1. 🧪 **Кислотный шейдер (Liquid Acid)** `[1]`: органическая переливающаяся плазма на GLSL WebGL с хроматической аберрацией на басах.
2. ⭕ **Неоновое кольцо (Neon Ring)** `[2]`: радиальный эквалайзер с пульсирующим энергетическим ядром, ударными волнами и вихрем из 250 светящихся частиц.
3. 🌆 **Ретровейв 80-х (Synthwave Grid)** `[3]`: 3D-сетка гор, бегущая на зрителя и изгибающаяся под частоты музыки, с неоновым солнцем и звездами.
4. 🌌 **Гиперпространство (Cosmic Tunnel)** `[4]`: полет сквозь бесконечный туннель геометрических неоновых колец с ускорением на дропах.
5. 📊 **3D Эквалайзер и Зеркало (Spectrum 3D)** `[5]`: футуристические глянцевые столбики с плавно падающими пиковыми метками и зеркальным полом.
6. 💻 **Матрица / Цифровой дождь (Matrix Rain)** `[6]`: потоки кибернетических символов, ускоряющиеся от темпа, с глитч-смещениями на бочке.
7. 🌀 **Спиральная Галактика (Galaxy Vortex)** `[7]`: вращающиеся рукава из 450 звезд со сверхновой вспышкой (Supernova) при ударе бочки.
8. 🌸 **Психоделическая Мандала (Mandala)** `[8]`: священная геометрия с 10-кратной симметрией, распускающая фрактальные лепестки под гармоники звука.
9. 🌐 **Кибер-сфера 3D (Cyber Sphere)** `[9]`: трехмерный вращающийся каркасный геодезический шар с гироскопическими орбитами, искажающийся от частот.
10. ⚡ **Лазерная плазма (Laser Plasma)** `[0]`: неоновые многослойные векторные лазерные лучи, плетущие 3D фигуры Лиссажу с электро-вспышками.
11. 🔥 **Огненный вихрь (Firestorm)** `[-]`: поднимающийся вихрь горящих искр и пламени с вулканическими выбросами на дропах.
12. 💎 **Кристаллические осколки (Crystal Shards)** `[=]`: парящие в пространстве 3D-призмы, преломляющие неоновый свет в ритм музыки.

## 📱 Беспроводной пульт со смартфона
- Откройте адрес `http://<IP-вашего-ПК>:3060/remote.html` на телефоне, подключенном к домашнему Wi-Fi.
- Переключайте все 12 пресетов, меняйте палитры, регулируйте чувствительность лежа на диване.
- Индикатор бита на экране телефона пульсирует синхронно с бочкой трека!

## 🚀 Быстрый запуск

### В 1 клик (Windows):
Дважды кликните по файлу **`start.bat`**.  
Он сам запустит сервер захвата звука и откроет визуализатор в полноэкранном окне.

---

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| **Space (Пробел)** | Следующий визуальный пресет (циклично из 12) |
| **1 .. 9, 0, -, =** | Мгновенный выбор любого из 12 пресетов |
| **F** или **F11** | Включить / выключить полноэкранный режим на проектор |
| **C** | Переключить цветовую палитру |
| **B** | Вкл / выкл строб-вспышку на бочку |
| **↑ / ↓** | Увеличить / уменьшить чувствительность |
| **H** | Скрыть / показать интерфейс |
