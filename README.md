# 📽️ Projector Music Visualizer (Музыкальный визуализатор для проектора)

Легковесный, ультра-производительный визуализатор музыки для ПК на Windows, спроектированный специально для вывода на подключенный проектор или второй монитор.

Захватывает любой звук, играющий на компьютере (Spotify, YouTube, браузер, игры, плееры) **напрямую из Windows WASAPI Loopback** в 100% цифровом качестве — без микрофонов, без виртуальных кабелей (Stereo Mix) и без необходимости давать разрешения в браузере.

---

## 🌟 Особенности

1. **Мгновенный чистый захват звука**:
   - Работает через встроенный в Windows WASAPI Loopback.
   - Задержка меньше 20 мс — графика бьет точно в такт бочке и басу.
   - Алгоритм детекции бита (Beat Detector) и FFT спектральное разложение на 48 частотных полос.

2. **Оптимизирован для проектора**:
   - **Глубокий черный фон (`#000000`)**: проектор не светит серыми рамками на стену, изображение органично сливается с комнатой.
   - **Авто-скрытие интерфейса**: через 2.5 секунды после движения мыши курсор и все панели плавно исчезают, оставляя только чистое световое шоу.
   - **Режим App-окна**: запускается без адресной строки и вкладок браузера.
   - **Полноэкранный режим**: в один клик или по клавише `F` / `F11`.

3. **5 контрастных визуальных пресетов**:
   - 🧪 **Кислотный шейдер (Liquid Acid)**: органическая переливающаяся плазма на GLSL WebGL с хроматической аберрацией, реагирующая на бас и средние частоты.
   - ⭕ **Неоновое кольцо (Neon Ring)**: радиальный эквалайзер с пульсирующим энергетическим ядром, ударными волнами и вихрем из 250 светящихся частиц.
   - 🌆 **Ретровейв 80-х (Synthwave Grid)**: 3D-сетка гор, бегущая на зрителя и изгибающаяся под частоты музыки, с неоновым солнцем и звездами.
   - 🌌 **Гиперпространство (Cosmic Tunnel)**: полет сквозь бесконечный туннель геометрических неоновых колец с ускорением на дропах.
   - 📊 **3D Эквалайзер и Зеркало (Spectrum 3D)**: футуристические глянцевые столбики с плавно падающими пиковыми метками и зеркальным полом.

4. **📱 Беспроводной пульт со смартфона**:
   - Откройте адрес `http://<IP-вашего-ПК>:3060/remote.html` на телефоне, подключенном к домашнему Wi-Fi.
   - Переключайте пресеты, меняйте палитры, регулируйте чувствительность лежа на диване.
   - Индикатор бита на экране телефона пульсирует синхронно с музыкой!

5. **6 неоновых цветовых палитр**:
   - Киберпанк (Циан / Неоновая маджента)
   - Закат (Огненный мандарин / Пурпур)
   - Матрица (Изумруд / Неоновый лайм)
   - Психоделика (Радужный спектр)
   - Аврора (Ледяной циан / Белый)
   - Пламя (Янтарный огонь / Алый)

## 🚀 Быстрый запуск

### Вариант 1 (Простой, в 1 клик):
Дважды кликните по файлу **`start.bat`**.  
Он сам запустит сервер захвата звука и откроет окно проектора.

### Вариант 2 (Через командную строку):
```bash
cd code/projector-music-visualizer
python server.py
```
Затем откройте в браузере: **`http://localhost:3060`**

## ⌨️ Горячие клавиши (в окне визуализатора)

| Клавиша | Действие |
|---|---|
| **Space (Пробел)** | Следующий визуальный пресет |
| **1, 2, 3, 4, 5** | Мгновенный выбор пресета |
| **F** или **F11** | Включить / выключить полноэкранный режим |
| **C** | Переключить цветовую палитру |
| **B** | Вкл / выкл строб-вспышку на бит |
| **↑ (Стрелка вверх)** | Увеличить чувствительность к тихой музыке |
| **↓ (Стрелка вниз)** | Уменьшить чувствительность |
| **H** | Скрыть / показать панель управления принудительно |

## 🛠️ Зависимости

Проект использует стандартные Python-библиотеки:
- `soundcard` (захват loopback с колонок Windows)
- `numpy` (быстрое преобразование Фурье FFT)
- `aiohttp` (асинхронный веб-сервер и WebSockets)
